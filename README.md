# Smart Expense Tracker 🦉

A minimalist, self-hosted expense tracker web application built for fast, lightweight, and private personal finance management.

## 🚀 Features
* **Real-time Expense Logging:** Easily record amounts, categories, dates, and descriptions.
* **Dashboard & Table Views:** Get quick visual insights into spending habits.
* **Lightweight & Fast:** Built with Go, requiring minimal system resources.
* **Local Data Persistence:** Stores your financial data securely on your local machine.

## 🛠️ Tech Stack
* **Backend:** Go (Golang)
* **Frontend:** HTML, CSS, JavaScript (Embedded via Go)
* **Storage:** File-based local storage
